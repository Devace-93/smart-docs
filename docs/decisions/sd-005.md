# SD-005 LLM tiers and rate limits

Status: Agreed (decision log, 2026-10-13).

Recommendation: four tiers selectable per account, hosted and local capped by you, agent mode uncapped, BYOK left open to decide while building EP-05, and one shared local embedding model for every tier.

| Tier | Who pays | Model | Limit | Enforced by |
|---|---|---|---|---|
| Hosted | The operator | DeepSeek V3 through the openai client | 30 requests per account per day (env `HOSTED_DAILY_LIMIT`) | Daily counter in Postgres, resets 00:00 UTC |
| Local | The operator's hardware | Ollama qwen2.5:3b | 1 request per 10 s, 20 per hour per account; one job at a time globally | Token bucket per account plus a single worker queue |
| BYOK (open, decide in EP-05) | The user's API account | Any OpenAI-compatible endpoint the user configures | None from SD; provider limits apply | Key stored encrypted with a server secret, or sent per request and never stored |
| Agent mode | The user's own plan | The MCP client's model | None | Client passes summary and tags on create; SD validates and stores, calls no model |

**Rules that apply to every tier.** Embeddings always run locally on nomic-embed-text, so search works the same whichever tier wrote the summary. A 429 carries `Retry-After` and `X-RateLimit-Limit`, `X-RateLimit-Remaining`, `X-RateLimit-Reset`. `GET /me/usage` returns today's counts so an agent can check before it spends quota. Self-hosters enable tiers with env flags; a fresh clone starts with local only.

**Optional classifier.** Jev (TypeSafe, $0.042 per million input tokens, output free, classification only) can rerank search results and run the publish safety check. Off by default, one env var to enable.

**Options considered.**

| Option | Why not |
|---|---|
| A. Four tiers as above | Recommended |
| B. Hosted only | Every self-hoster needs a DeepSeek key; no free path |
| C. Login with Claude, OpenAI or Gemini to bill the user's chat plan | Does not exist; consumer plans cannot be used by third-party apps. BYOK and agent mode are the honest versions |

**Consequences.** Cost to the operator at 100 daily-active users on the hosted cap is about $45 a month at DeepSeek prices; set a spend cap at the provider anyway. Local tier throughput is bounded by one GPU, so the queue is not optional.

**Decision:** Enrique sets the status in the index.
