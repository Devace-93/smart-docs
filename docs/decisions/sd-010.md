# SD-010 Evals

Status: Agreed (decision log, 2026-10-13).

Recommendation: four small eval sets that run with one command, results committed as JSON and rendered as a table in the README, with the local model and DeepSeek as two columns from day one.

| Eval | Data | Metric | Passes when |
|---|---|---|---|
| Search | 15 seeded pages (this decision log, the 3m4 plan, the bubbles README), 30 hand-written queries with one expected page each | hit@1, hit@3, MRR | hit@3 at or above 0.9 |
| Summary | The same 15 pages | Rubric scored by an LLM judge (Claude Haiku): under 40 words, names the page's subject, no number absent from the source; 5 pages also checked by hand | 13 of 15 pass |
| Tags | The same 15 pages with 3 to 5 hand tags each | Jaccard overlap with the hand tags | Mean at or above 0.5 |
| MCP tasks | 10 tasks an agent must complete through the MCP client, e.g. \"create a page under docs/api and publish it\" | Task success, tool calls used, wall time | 9 of 10 succeed |

**Columns.** Every eval runs per provider: `local` (qwen2.5:3b), `hosted` (DeepSeek V3), and `byok` when an OpenAI key is present. Latency p50 and cost per page are recorded next to the quality numbers, so the README answers \"why would I pay\" with data.

**Where it lives.** `evals/data/` holds the pages, queries and hand labels. `uv run sd-evals` writes `evals/results/<date>-<provider>.json` and regenerates the README table. Failure cases are appended to `docs/evals-failures.md` with one line each, because the failures are the interview story.

**Options considered.**

| Option | Why not |
|---|---|
| A. Four small sets, committed results | Recommended |
| B. promptfoo | Good tool, but a second config language for a one-night project |
| C. Search eval only | Leaves summaries and MCP untested, the parts agents rely on most |

**Consequences.** CI runs unit tests and the search eval against a cached embedding fixture; model evals run on Enrique's machine and their JSON is committed. The eval data is public and contains only his own documents.

**Decision:** Enrique sets the status in the index.
