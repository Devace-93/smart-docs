# SD-009 License and self-hosting

Status: Agreed (decision log, 2026-10-13).

Recommendation: MIT license, so anyone can clone, modify and deploy with nothing owed beyond keeping the copyright line, plus a removable \"Built with Smart Docs\" link on public pages as the polite ask.

| Option | What a self-hoster owes | Why not |
|---|---|---|
| A. MIT | Keep the copyright and license text in the repo | Recommended: the \"minor mention\" is exactly the MIT notice, and it is the license FastAPI and most of the stack use |
| B. Apache-2.0 | Same as MIT plus a NOTICE file and a patent grant | Fine, but heavier than the project needs; the NOTICE file confuses first-time forkers |
| C. AGPL-3.0 | Publish their modifications if they run it as a service | Forces obligations Enrique said he does not want |
| D. MIT with a mandatory attribution footer | Keep a visible link on every public page | Not MIT anymore; forks remove it and resent it |

**Self-hosting contract.** One command: `docker compose up` brings up api, worker and db; `--profile local` adds Ollama. `.env.example` lists every variable with a one-line reason. First boot runs migrations and the queue schema. No telemetry, no phone-home, no license key. The instance name and public footer text are env variables; the footer defaults to \"Built with Smart Docs\" linking to the repo and can be set to empty.

**Repo layout.** `README.md` (install in five lines, then the eval table), `docs/decisions/` (this log, one file per DEC), `docs/for-agents.md` (how to point an MCP client at an instance), `CONTRIBUTING.md`, `LICENSE`.

**Consequences.** Anyone can run a commercial SD instance without paying or crediting beyond the notice. Enrique's own public instance is just one deployment of the same repo, with the hosted tier switched on.

**Decision:** Enrique sets the status in the index.
