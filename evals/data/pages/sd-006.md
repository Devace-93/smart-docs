# SD-006 Public surface and machine docs

Status: Agreed (decision log, 2026-10-13).

Recommendation: every public page exists in three forms at predictable URLs, and every project publishes an `llms.txt` that is generated, never hand-written.

| Route | Returns | For whom |
|---|---|---|
| `GET /{owner}/{project}/{path}` | Sanitized HTML with title, summary, tags, updated date, and a link to the Markdown | People and crawlers |
| `GET /{owner}/{project}/{path}.md` | Raw Markdown with a small YAML front matter (title, summary, tags, updated, canonical URL) | Agents and anyone who copies |
| `GET /{owner}/{project}/llms.txt` | Project name, one-line description, then one line per public page: title, summary, `.md` link | Agents and LLM crawlers, per the llms.txt convention |
| `GET /{owner}/{project}/llms-full.txt` | All public pages concatenated as Markdown | Agents that want the whole project in one fetch |
| `GET /openapi.json` and `/docs` | The FastAPI spec and Swagger UI | Agents that drive the API directly |

**Rules.** Public routes need no auth and set long cache headers plus an `ETag` from the page version. Private pages return 404, not 403, so their existence is not leaked. HTML is rendered from Markdown by the worker and cached on the page row; `nh3` strips scripts and event handlers before caching. Front matter and `llms.txt` lines are rebuilt when a page is saved, published or unpublished.

**Options considered.**

| Option | Why not |
|---|---|
| A. Three forms per page plus generated `llms.txt` | Recommended |
| B. HTML only | Agents would have to scrape; the machine-docs checkbox stays unticked |
| C. Markdown only, no HTML | People get a wall of text with no navigation; the 3m4.net blog use case dies |

**Consequences.** `path` in the URL is the node's materialized path, so a move changes the URL; the old path returns 404 in the MVP, a redirect table is a later SD. The public index of all public projects on the instance is out of MVP scope.

**Decision:** Enrique sets the status in the index.
