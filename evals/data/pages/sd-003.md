# SD-003 Stack

Status: Agreed (decision log, 2026-10-13).

Recommendation: Python and FastAPI on Postgres, with the fewest moving parts that still give retries, vectors and a real worker.

| Layer | Pick | Alternative considered | Why the pick |
|---|---|---|---|
| Language | Python 3.12 with uv, ruff, pytest | TypeScript (his daily stack) | Python leads for LLM, embedding and eval tooling; learning plan D3.1 and D3.2 |
| Web | FastAPI + Pydantic v2 | Flask (bubbles, 3m4) | Typed models drive the OpenAPI spec agents read |
| Database | Postgres 16 + pgvector, SQLAlchemy 2 async, Alembic | SQLite for the night | One engine in dev and prod; vectors without a second store |
| Queue | procrastinate (Postgres-backed jobs, retries) | arq + Redis, Celery, BackgroundTasks | No Redis container; retries and dead jobs are visible in SQL |
| LLM client | openai SDK against any OpenAI-compatible base URL | litellm | One client for DeepSeek, Ollama, OpenRouter and BYOK |
| Embeddings | nomic-embed-text via Ollama, 768 dims | OpenAI text-embedding-3-small | Free, local, one vector space for every tier |
| MCP | mcp Python SDK (FastMCP) | Hand-rolled JSON-RPC | Official SDK, stdio and HTTP transports |
| Auth | argon2-cffi + PyJWT | fastapi-users | Same recipe as bubbles; nothing to learn |
| Markdown | markdown-it-py + nh3 sanitizer + Jinja2 | mistune | CommonMark-compliant; nh3 blocks script injection on public pages |
| Tests | pytest, httpx AsyncClient, testcontainers Postgres | SQLite in tests | Tests hit the real engine |
| Packaging | Docker Compose: api, worker, db, ollama (profile) | Single container | Self-hosters pick tiers by enabling profiles |

**Consequences.** Two things are new for Enrique: FastAPI and async SQLAlchemy. Everything else is known or copied from bubbles. procrastinate needs a `schema apply` step on first boot; the Compose file runs it.

**Decision:** Enrique sets the status in the index.
